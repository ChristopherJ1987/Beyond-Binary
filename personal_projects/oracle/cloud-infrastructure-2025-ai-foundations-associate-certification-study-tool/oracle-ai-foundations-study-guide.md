### e) AI vs ML vs DL

#### Artificial Intelligence (AI)
**Definition**: The broader concept of creating machines or systems that can perform tasks that typically require human intelligence.

**Example**: Self-driving car that makes human-like decisions:
- Navigating traffic
- Detecting pedestrians
- Making safe lane changes

#### Machine Learning (ML)
**Definition**: A subset of AI that focuses on developing algorithms that enable machines to learn from and make predictions or decisions based on data.

**Example**: Spam email filter that learns to identify and move spam emails based on:
- User interactions
- Email content patterns

**Algorithm Definition**: A specific set of rules, mathematical equations, or procedures that the machine learning model follows to learn from data and make predictions.

#### Deep Learning (DL)
**Definition**: A subfield of ML that uses neural networks with many layers (deep neural networks) to learn and make sense of complex patterns in data.

**Example**: Image recognition software that identifies specific objects or animals:
- Recognizing cats in photos
- Complex pattern recognition from raw pixel data

#### Types of Machine Learning

##### 1. Supervised Learning
**Definition**: Algorithm learns from labeled data, making predictions or classifications.

**Credit Card Approval Example**:
- **Traditional Process**: Manual verification → Credit score check → 10-15 days approval
- **Manual/Rules Engine Approach**:
  - Drawbacks: Slow, requires skilled people, rules constantly change
  - Benefits: Business insight into decision-making process
- **ML Approach**: Train model using past credit card approval history
  - Uses labeled data (approved/denied examples)
  - Model learns patterns to predict new applications
  - **Process**: Training → Model Building → Prediction on new data

##### 2. Unsupervised Learning
**Definition**: Algorithm discovers patterns and structures in unlabeled data through clustering or dimensionality reduction.

**Key Characteristics**:
- Data has no specific outcome or label
- Discovers trends for potential insights
- Groups similar data into clusters

**Examples**:
- **Retail Marketing**: Cluster customers by household size, income, location, occupation
  - Identifies groups like "small family" or "high spender"
  - Used for targeted marketing and sales
- **Streaming Services**: Analyze viewing sessions, minutes per session, unique shows watched
  - Optimize service delivery and recommendations
- **Nutritional Analysis**: Cluster fruits and vegetables by nutritional content
  - Identify nutritionally similar foods
  - Help create balanced diets with diverse nutrition

##### 3. Reinforcement Learning
**Definition**: Agents learn to make decisions by interacting with an environment and receiving rewards or punishments.

**Learning Process** (Chess Example):
1. **Action**: Make a move/decision
2. **Feedback**: Check if it's the right move
3. **Learning**: Keep outcomes in memory for next steps
4. **Iteration**: Trial and error approach

**Applications**:
- Autonomous car driving
- Robotics
- Game playing (chess, Go, etc.)

#### Deep Learning Details

##### Core Concept
**Purpose**: Extracting features and rules from raw data automatically

**Key Questions**:
- Can we identify a cat vs dog from one pixel? (No)
- Can we write rules to identify cats vs dogs? (Difficult)
- Can features and rules be extracted from raw pixels? (Yes, with deep learning)

##### Neural Networks
**Definition**: Connected layers of neurons that work like brain cells stacked together

**Characteristics**:
- Example of supervised machine learning algorithm
- Best understood in context of functional approximation
- **Functional Approximation**: Estimating hidden functions by examining past/current data from specific domains

**Deep Learning Process**:
- Uses "super smart" computer networks with many layers
- Networks learn autonomously from pictures
- Automatically figures out complex patterns (cat vs dog identification)

#### Generative AI

##### Definition
**Generative AI**: A subset of machine learning that creates diverse content like text, audio, images, and more.

##### How It Works
- Models powered by neural networks
- Learn patterns from existing data
- Craft fresh and creative output

##### Examples
- **ChatGPT**: Generates text responses by understanding patterns in training text data
- **Image Generation**: Creates new images from text descriptions
- **Audio Creation**: Synthesizes speech and music

##### Applications
- Content creation tasks
- Innovation and creative processes
- Various AI tasks requiring new content generation

#### How Machine Learning Works

##### Training Process Example: Cat vs Dog Classification

**Step 1: Define Input Features**
- Identify distinguishing characteristics between cats and dogs:
  - **Body color**
  - **Texture**
  - **Eye color**
  - Other defining physical features

**Step 4: Inference Phase**

- **Application**: Input new animal features → Trained model predicts "cat" or "dog"
- **Real-world Use**: Model can classify new, unseen animals based on learned patterns

### c) Supervised Learning - Regression

#### What is Supervised Learning?
**Definition**: A machine learning model that learns from labeled data, discovering the mapping between input and output.

**Key Concept**: The model learns the relationship between input data and corresponding target values using past examples with known outcomes.

#### How Supervised Learning Works

##### Teacher-Student Analogy
- **Teacher Role**: Historical data with known outcomes
- **Student Role**: Machine learning model
- **Learning Process**: Model discovers patterns from past input-output relationships
- **Application**: Use learned patterns to predict outcomes for new data

##### Input-Output Mapping
**Fundamental Concept**: Teaching a model to learn the relationship between input data and corresponding output values.

**Process**:
1. Provide labeled training examples
2. Model identifies patterns and relationships
3. Model learns mapping function
4. Apply learned function to make predictions on new data

#### Types of Supervised Learning Outputs

##### Regression (Continuous Output)
- **Output Type**: Continuous numerical values
- **Examples**: House prices, stock prices, temperature, sales revenue
- **Use Case**: When predicting quantities or measurements

##### Classification (Categorical Output)
- **Output Type**: Discrete categories or classes
- **Examples**: Spam/not spam, disease/no disease, positive/negative sentiment
- **Use Case**: When predicting categories or labels

#### Linear Regression Deep Dive

##### House Price Prediction Example

**Dataset Structure**:
- **Independent Feature (Input)**: House size in square feet
- **Dependent Feature (Output)**: House price in dollars
- **Training Example**: Single row of input-output pair (tuple)
- **Training Dataset**: Complete table of house size and price pairs

**Key Terminology**:
- **Independent Feature**: Input variable that influences the outcome
- **Dependent Feature**: Output variable that depends on the input
- **Training Example**: One input-output pair
- **Tuple**: Another term for a single training example

##### Visualization and Analysis

**Scatter Plot Analysis**:
- **Purpose**: Visualize relationship between input and output
- **Observation**: As house size increases, price increases (positive correlation)
- **Pattern**: Data points show linear relationship trend

**Line Fitting Process**:
- **Goal**: Find straight line that best represents the data relationship
- **Application**: Use line to predict prices for new house sizes
- **Example**: For 1100 sq ft house, find corresponding price on the line

**Parameter Roles**:
- **Slope (w)**: Rate of change of house price with respect to house size
- **Bias (b)**: Y-intercept, moves line up or down
- **Weight**: Another term for slope in machine learning context

##### Model Training Process

**Parameter Adjustment**:
- **Slope Adjustment**: Tilts line upward or downward
- **Bias Adjustment**: Moves line up or down vertically
- **Iterative Process**: Continuously adjust parameters to find best fit
- **Goal**: Position line to accommodate most data points

**Error and Loss Concepts**:
- **Error**: Difference between predicted and actual values
- **Loss**: Penalty for bad predictions
- **Perfect Prediction**: Loss equals zero
- **Poor Prediction**: High loss value

**Loss Calculation Method**:
- **Squared Loss**: Take difference between predicted and actual, then square it
- **Formula**: (Predicted - Actual)²
- **Optimization**: Algorithm minimizes squared loss iteratively
- **Convergence**: Arrive at optimal weight and bias values

##### Training Summary Process

**Step 1: Data Preparation**
- Provide input-output value pairs (dataset)
- Ensure data quality and completeness

**Step 2: Learning Phase**
- Algorithm learns function f (mapping function)
- Function represents the trained model
- Model captures input-output relationships

**Step 3: Prediction Phase**
- Input new house size to trained model
- Learned function predicts corresponding house price
- Apply model to make real-world predictions

**Complete Workflow**:
1. **Training Data** → 2. **Algorithm Learning** → 3. **Trained Model** → 4. **Predictions**

### d) Supervised Learning - Classification

#### Classification vs Regression Review
**Output Type Determines Approach**:
- **Continuous Output** → Use **Regression** (predicts numeric values)
- **Categorical Output** → Use **Classification** (predicts categories/labels)

**Examples**:
- **Regression**: House price prediction (continuous dollar amounts)
- **Classification**: Email spam detection (categorical: spam/not spam)

#### What is Classification?
**Definition**: A supervised learning problem where the goal is to assign a category or label to the outcome based on input features.

**Core Purpose**: Categorize or assign data points into predefined classes or categories based on their features or attributes.

**Training Process**: Classifier is trained on a labeled dataset with known category assignments.

#### Types of Classification

##### Binary Classification
**Definition**: Classification with exactly two possible output categories.

**Examples**:
- **Email Spam Detection**: Spam or Not Spam
- **Medical Diagnosis**: Disease Present or Absent  
- **Pass/Fail Prediction**: Pass or Fail
- **Fraud Detection**: Fraudulent or Legitimate

**Output**: Binary outcome (two classes only)

##### Multi-Class Classification
**Definition**: Classification with three or more possible output categories.

**Examples**:
- **Sentiment Analysis**: Positive, Negative, or Neutral
- **Image Recognition**: Multiple object categories
- **Grade Classification**: A, B, C, D, or F
- **Flower Species**: Multiple species identification

**Output**: One of multiple possible classes (3+ categories)

#### Logistic Regression Algorithm

##### What is Logistic Regression?
**Definition**: A machine learning algorithm used for classification that predicts if something is true or false (or belongs to a specific category).

**Key Difference from Linear Regression**:
- **Linear Regression**: Uses straight line to fit data
- **Logistic Regression**: Uses S-shaped curve (sigmoid function) to fit data

##### Pass/Fail Prediction Example

**Problem Setup**:
- **Input Feature**: Hours of study (independent variable)
- **Output**: Binary classification (Pass or Fail)
- **Goal**: Predict student performance based on study time

**Classification Process**:
- Students belong to either **Pass Class** (passed the test) or **Fail Class** (failed the test)
- Classification depends on hours of study input

##### Sigmoid Function

**Mathematical Properties**:
- **Shape**: S-shaped curve
- **Input Range**: Any real-valued number
- **Output Range**: Squashed between 0 and 1
- **Purpose**: Essential for interpreting output as probability

**Function Behavior**:
- **Input**: Hours of study
- **Output**: Probability of passing the test (0 to 1)
- **Interpretation**: Higher probability = more likely to pass

##### Decision Making with Threshold

**Threshold Concept**:
- **Common Threshold**: 0.5 (50% probability)
- **Decision Rule**: 
  - If probability > 0.5 → Classify as **Pass**
  - If probability < 0.5 → Classify as **Fail**

**Practical Examples**:
- **Student A**: 6 hours study → 80% probability → **Pass Classification**
- **Student B**: 4 hours study → 20% probability → **Fail Classification**

**Solution**: Standardization ensures all features are treated equally by the model.

##### House Price Prediction Example

**Scenario**: Predicting house prices with two features
- **Feature 1**: Square footage (ranges 1,000 - 5,000)

**Without Standardization**:
- Model gives more weight to square footage (larger values)
- Number of bedrooms gets less consideration
- Results in inaccurate model despite bedrooms being significant predictor

**With Standardization**:
- Both features scaled to comparable means and standard deviations
- Model treats both features equally
- More accurate predictions result

**Learning**: Child discovers patterns without explicit instructions (unsupervised learning)

### i) Reinforcement Learning

#### Core Concepts of Reinforcement Learning

##### Primary Goal
**Objective**: Find the policy that will yield the most rewards for the agent when following that policy.

**Optimal Policy**: The best strategy or set of actions that maximizes cumulative rewards over time.

##### Learning Process
**Method**: Learning from experiences and feedback through trial and error
**Progression**: Agent becomes more proficient at making good decisions and accomplishing tasks
**Outcome**: Eventually develops optimal policy through continuous learning

##### Training Algorithms
**Common Algorithms**:
- **Q-Learning**: Value-based method for learning optimal actions
- **Deep Q-Learning**: Neural network-based extension of Q-learning
- **Policy Learning**: Direct optimization of action strategies

#### Practical Example: Robotic Arm in Warehouse

##### Application Scenario
**Use Case**: Optimize robotic arm process for placing goods in warehouse
**Primary Goal**: Teach robotic arm to pick up and place items efficiently and accurately
**Target Outcome**: Automated warehouse operations with optimal item placement

#### Reinforcement Learning Training Steps

##### Step 1: Setting the Environment
**Environment Components**:
- **Robotic Arm**: The learning agent that performs actions
- **Warehouse Layout**: Physical space and structure constraints
- **Goods to be Placed**: Items that need to be moved and organized
- **Target Locations**: Designated positions where each item should be placed

**Environment Purpose**: Provides the context and constraints within which the agent operates

##### Step 2: Define State Representations
**State Information for Robotic Arm**:
- **Arm Position**: Current location of the robotic arm in 3D space
- **Arm Orientation**: Angular position and rotation of arm joints
- **Item Positions**: Locations of items available for pickup
- **Target Locations**: Positions where items need to be placed
- **Environmental Constraints**: Obstacles, boundaries, and workspace limits

**State Purpose**: Provides complete information about current situation for decision-making

##### Step 3: Define Action Space
**Action Space Definition**: Set of all possible actions the robotic arm can take in each state

**Possible Actions**:
- **Movement Actions**: Move arm to different positions
- **Rotation Actions**: Adjust arm orientation and joint angles
- **Gripper Actions**: Open/close gripper to pick up or release items
- **Navigation Actions**: Move between pickup and placement locations
- **Precision Actions**: Fine-tune positioning for accurate placement

**Action Space Purpose**: Defines the range of choices available to the agent

##### Step 4: Decide Rewards and Penalties
**Reward System Design**: Critical for guiding learning toward desired behaviors

**Positive Rewards (Reinforcement)**:
- **Successful Placement**: High reward for correctly placing item in target location
- **Efficient Movement**: Reward for completing tasks quickly
- **Accurate Positioning**: Reward for precise item placement
- **Task Completion**: Bonus reward for completing full warehouse operations

**Penalties (Negative Reinforcement)**:
- **Dropping Items**: Penalty for losing grip on items during transport
- **Damaging Goods**: Significant penalty for causing item damage
- **Inaccurate Placement**: Penalty for placing items in wrong locations
- **Inefficient Actions**: Small penalty for unnecessary or wasteful movements
- **Collision Events**: Penalty for hitting obstacles or workspace boundaries

##### Step 5: Training Process
**Training Methodology**: Iterative learning through experience

**Initial Phase - Exploration**:
- **Random Start**: Robotic arm begins in random state
- **Random Actions**: Initially explores different actions randomly
- **Observation**: Records rewards and penalties received for each action
- **Experience Collection**: Builds database of state-action-reward experiences

**Learning Phase - Exploitation**:
- **Pattern Recognition**: Identifies which actions lead to higher rewards
- **Strategy Development**: Prioritizes actions that consistently yield positive outcomes
- **Penalty Avoidance**: Learns to avoid actions that result in penalties
- **Policy Refinement**: Continuously improves decision-making strategy

**Optimization Phase - Mastery**:
- **Multiple Iterations**: Repeats training cycles to refine performance
- **Strategy Improvement**: Develops better strategies for picking and placing items
- **Efficiency Gains**: Learns faster and more accurate warehouse operations
- **Optimal Policy**: Converges on best possible strategy for the task

**Step 1: Forward Pass**
- Show image to ANN (e.g., image of digit 2)

#### Recurrent Neural Networks (RNNs)

##### Definition and Architecture
**RNN**: A class of neural network architectures specifically designed to handle sequential data.

##### Key Difference from Traditional Networks
**Traditional Feedforward Networks**: Information flows in one direction only
**RNNs**: Have feedback loops that allow information to persist across different time steps

##### Core Features of RNNs

**Internal State Maintenance**:
- **Hidden State**: Internal memory that persists across time steps
- **Memory Function**: Often referred to as the network's memory
- **State Updates**: Hidden state is updated as network processes each sequence element

**Temporal Processing**:
- **Time Step Processing**: Network processes one element at a time in sequence
- **Information Persistence**: Previous information influences current processing
- **Dependency Capture**: Can capture patterns and dependencies spread across time

##### RNN Processing Mechanism
1. **Input Processing**: Network receives current sequence element
2. **State Integration**: Combines current input with previous hidden state
3. **State Update**: Updates hidden state based on current processing
4. **Output Generation**: Produces output for current time step
5. **State Forwarding**: Hidden state becomes input for next time step
6. **Sequence Continuation**: Process repeats for each element in sequence

#### Types of RNN Architectures

##### 1. One-to-One Architecture
**Structure**: Single input → Single output
**Characteristics**: Similar to feedforward neural networks
**Suitability**: Not suited for sequential data processing
**Use Cases**: Traditional classification or regression tasks

##### 2. One-to-Many Architecture
**Structure**: Single input → Multiple outputs
**Processing**: Produces multiple output values for one input value
**Applications**:
- **Music Generation**: Creating musical sequences from single input
- **Sequence Generation**: Generating text or data sequences
- **Image Captioning**: Creating multiple words describing single image

##### 3. Many-to-One Architecture
**Structure**: Multiple inputs → Single output
**Processing**: Produces one output value after receiving multiple input values
**Applications**:
- **Sentiment Analysis**: Analyzing entire review to determine sentiment
- **Document Classification**: Categorizing entire documents
- **Sequence Classification**: Classifying entire sequences into categories

##### 4. Many-to-Many Architecture
**Structure**: Multiple inputs → Multiple outputs
**Processing**: Produces multiple output values for multiple input values
**Applications**:
- **Machine Translation**: Converting sentences between languages
- **Named Entity Recognition**: Identifying entities throughout text
- **Sequence-to-Sequence Tasks**: Various text processing applications

#### RNN Limitations

##### Vanishing Gradients Problem
**Issue**: RNNs do not perform well when capturing long-term dependencies
**Cause**: Gradients become very small as they propagate back through many time steps
**Effect**: Network loses ability to learn from distant past information
**Impact**: Limits effectiveness for long sequences

##### Solution Approach
**Problem Resolution**: Vanishing gradients problem is overcome by using LSTM models
**Advanced Architecture**: LSTM provides better long-term memory capabilities

#### Long Short-Term Memory (LSTM)

##### Definition and Purpose
**LSTM**: Advanced RNN architecture that works by using specialized memory cells and gating mechanisms to capture long-term dependencies in sequential data.

##### Core Innovation
**Key Idea**: Selectively remember or forget information over time
**Capability**: Maintain relevant information over long sequences
**Advantage**: Helps overcome the vanishing gradients problem

##### LSTM Architecture Components

**Memory Cell**:
- **Specialized Storage**: Advanced memory mechanism beyond simple hidden state
- **Long-term Storage**: Designed to maintain information over extended sequences
- **Selective Retention**: Can choose what information to keep or discard

**Gating Mechanisms**:
- **Information Control**: Gates act as filters controlling information flow
- **Selective Processing**: Determine what information passes through LSTM cell
- **Three Gate Types**: Input gate, forget gate, and output gate

#### LSTM Step-by-Step Processing

##### Step 1: Input Reception
**Current Input**: LSTM receives input vector representing current data point in sequence
**Previous States**: Receives previous hidden state and cell state
**State Significance**: Previous states represent what LSTM has remembered and forgotten up to current point

##### Step 2: Gating Mechanisms

**Input Gate**:
- **Function**: Decides what new information from current input should be added to memory cell
- **Selection Process**: Filters relevant new information for storage
- **Memory Update**: Controls what gets added to long-term memory

**Forget Gate**:
- **Function**: Determines what information in current memory cell should be discarded or forgotten
- **Memory Cleanup**: Removes irrelevant or outdated information
- **Selective Forgetting**: Maintains only useful information for future processing

**Output Gate**:
- **Function**: Regulates how much of current memory cell should be exposed as output
- **Information Control**: Controls what information is revealed at current time step
- **Output Regulation**: Determines current step's contribution to sequence processing

##### Step 3: Cell State Update
**Process**: Using information from input gate and forget gate, LSTM updates the cell state
**Integration**: Combines new information (from input gate) with retained information (after forget gate)
**Memory Maintenance**: Maintains updated long-term memory for future processing

##### Step 4: Hidden State Generation
**Output Production**: LSTM uses output gate to produce current hidden state
**State Forwarding**: Hidden state becomes output of LSTM for current time step
**Next Step Input**: Current hidden state becomes input for next time step processing

##### Step 5: Sequence Continuation
**Iterative Process**: Steps repeat for each element in input sequence
**Temporal Processing**: Maintains memory and dependencies across entire sequence
**Long-term Learning**: Captures patterns spanning extended time periods

#### LSTM Advantages Over Standard RNNs

##### Long-term Dependency Capture
- **Extended Memory**: Can remember information over much longer sequences
- **Gradient Stability**: Solves vanishing gradients problem through gating mechanisms
- **Selective Memory**: Chooses what to remember and forget intelligently

##### Improved Performance
- **Better Accuracy**: More accurate predictions on long sequences
- **Robust Learning**: More stable training process
- **Versatile Applications**: Suitable for wide range of sequential tasks

##### Practical Benefits
- **Real-world Applicability**: Better performance on practical sequential problems
- **Scalability**: Can handle longer and more complex sequences
- **Reliability**: More consistent results across different sequence types

#### Sequence Models Summary

##### Model Selection Guidelines
**Standard RNNs**:
- **Best For**: Short sequences with simple dependencies
- **Limitations**: Struggles with long-term dependencies
- **Use Cases**: Basic sequential tasks with limited context requirements

**LSTM Networks**:
- **Best For**: Long sequences requiring extended memory
- **Advantages**: Overcomes vanishing gradients, better long-term learning
- **Use Cases**: Complex sequential tasks, language modeling, time series with long patterns

### c) Introduction to Large Language Models

#### What is a Language Model?

##### Definition
**Language Model**: A probabilistic model of text that determines the probability of a given sequence of words occurring in a sentence based on the previous words.

**Core Function**: Helps predict which word is more likely to appear next in a sentence.

#### Language Model Example: Zoo Story

##### Sample Sentence
**Input**: "I wrote to the zoo to send me a pet. They sent me ___"
**Source**: Opening from a children's book
**Task**: Predict what word should fill the blank

##### Probability Distribution Process

**Step 1: Vocabulary Analysis**
- Language model computes probability distribution over its vocabulary
- **Vocabulary**: Set of words that could potentially appear in the blank
- **Relevant Words**: Lion, elephant, dog, cat, panther (zoo-related animals)

**Step 2: Probability Assignment**
- Model assigns probability to every word in vocabulary for appearing in blank
- **Example Probabilities**:
  - Lion: 0.03
  - Elephant: 0.02
  - Dog: 0.45
  - Cat: (probability assigned)
  - Panther: (probability assigned)

**Step 3: Vocabulary Constraints**
- Model only provides probabilities for words within its vocabulary
- **Excluded Words**: Car, truck, building (not contextually relevant)
- **Included Words**: Animals related to zoo context
- **Context Relevance**: Each word receives probability based on sentence context

#### What Makes Language Models "Large"?

##### Size Definition
**"Large" Reference**: Refers to the number of parameters in the model
**No Fixed Threshold**: No agreed-upon threshold for when a model becomes "large" vs "small"
**Common Term**: All these models collectively referred to as Large Language Models (LLMs)

#### Word Selection and Generation Process

##### Selection Method
**Rule**: Pick the word in vocabulary with the highest probability
**Example**: Dog has highest probability (0.45), so it gets selected

##### Step-by-Step Generation Process

**Step 1: Initial Prediction**
- Input: "I wrote to the zoo to send me a pet. They sent me ___"
- Highest probability word: "dog" (0.45)
- Action: Select "dog" and append to input

**Step 2: Updated Input Processing**
- New input: "I wrote to the zoo to send me a pet. They sent me a dog"
- Feed updated sentence back to model
- **Key Observation**: Probabilities change significantly

**Step 3: Probability Changes**
- **Elephant**: Drops from 0.02 to 0.001
- **Dog**: Probability decreases further
- **All words**: Generally get much lower probabilities
- **New token appears**: EOS (End of Sentence/End of Sequence)

**Step 4: Sequence Completion**
- **EOS Token**: Has very high probability
- **Model Decision**: Sentence should end after "dog"
- **Final Output**: "I wrote to the zoo to send me a pet. They sent me a dog." [EOS]

**Step 5: Generation Complete**
- After EOS token, model stops generating
- Complete sentence returned to user

### d) Transformers Part 1

#### The Challenge of Language Understanding for Machines

##### Example Sentence Analysis
**Sample Sentence**: "Jane threw the Frisbee and her dog fetched it."

**Human Understanding** (Easy):
- **Jane**: Performs the throwing action
- **Dog**: Performs the fetching action  
- **Frisbee**: Object being thrown
- **"It"**: Clearly refers to the frisbee

**Machine Understanding** (Challenging):
- Determining what "it" refers to is computationally difficult
- Requires understanding relationships between distant words
- Context and reference resolution are complex tasks

#### Traditional Approach: Recurrent Neural Networks (RNNs)

##### RNN Architecture Review
**Definition**: A class of neural network architectures specifically designed to handle sequential data
**Design Purpose**: Process sequences like sentences and text data

##### Key RNN Features

**Feedback Loop**: 
- Allows information to persist across different time steps
- Enables processing of sequential data effectively

**Internal State Management**:
- **Hidden State**: Internal memory that updates as network processes each sequence element
- **Memory Function**: Often referred to as the network's memory
- **Sequential Processing**: Hidden state used as input for next time step

**Dependency Capture**:
- Captures dependencies and patterns spread across time
- Maintains context from previous elements in sequence

##### RNN Processing Example

**Sequential Processing Steps**:
- **Step 1**: Model knows only "Jane"
- **Step 2**: Model knows "Jane" and "threw" (but not "frisbee" or "and")
- **Step 3**: Model knows "Jane," "threw," and "and" (continuing sequentially)
- **Pattern**: Processes one element at a time, building knowledge incrementally

#### RNN Limitations

##### Sequential Processing Constraints
**One-at-a-Time Processing**: RNNs process input data one element at a time
**Hidden State Dependency**: Must maintain hidden state throughout processing
**Limited Context Window**: Can only capture dependencies between nearby words

##### Long-Range Dependency Problems
**Distance Limitation**: Struggle to connect words that are far apart in sentences
**Context Degradation**: Model's ability to retain relevant context weakens as sequence grows
**Vanishing Gradient**: Phenomenon where long-range dependencies become challenging to capture
**Understanding Limitation**: Limits RNN's ability to understand entire sequence comprehensively

#### Transformer Architecture Revolution

##### Global Relationship Understanding
**Core Innovation**: Transformers understand relationships between all words in a sentence simultaneously
**Visual Representation**: Interconnections between all different words in the sentence
**Comprehensive View**: Model has "bird's eye view" of entire sentence

##### Simultaneous Processing Advantage
**Parallel Analysis**: Can look at all words in sentence at the same time
**Relationship Mapping**: Understands how all words relate to each other

#### Tokens and Tokenization

##### What are Tokens?
**Token Definition**: Basic units that large language models understand (not words)

**Token Types**:
- **Entire Word**: Common words like "apple"
- **Part of Word**: Complex words broken into pieces
- **Punctuation**: Symbols like commas, periods, colons

##### Tokenization Examples

**Simple Words**:
- **"Apple"**: 1 token (entire word)
- **Common words**: Generally 1 token each

**Complex Words**:
- **"Friendship"**: 2 tokens ("friend" + "ship")
- **"Indivisible"**: 2 tokens (less frequently encountered word)

**Punctuation**:
- **Comma (,)**: 1 token
- **Period (.)**: 1 token  
- **Colon (:)**: 1 token

##### Token-to-Word Ratios

**Simple Text**: 1 token per word on average
- Contains common, frequently used words
- Straightforward vocabulary

**Complex Text**: 2-3 tokens per word on average
- Contains fewer common words
- More specialized or technical vocabulary
- Higher complexity requires more tokenization

##### Practical Tokenization Example
**Sample Sentence**: "Many words map to tokens, including: punctuation."
**Total Tokens**: 15 tokens

**Token Breakdown**:
- **Simple words**: "many," "words," "map" (1 token each)
- **Complex words**: "indivisible" (2 tokens)
- **Punctuation**: Comma, colon, period (separate tokens)

#### Embeddings

##### Definition and Purpose
**Embeddings**: Numerical representations of pieces of text
**Text Scope**: Can represent words, phrases, sentences, paragraphs, or multiple paragraphs
**Computer Understanding**: Make it easy for computers to understand relationships between text pieces

##### Embedding Creation Process

**Step 1: Tokenization**
- **Input**: "They sent me a" (phrase from LLM lesson)
- **Tokens**: "they," "sent," "me," "a" (4 individual tokens)

**Step 2: Encoder Processing**
- **Input**: Tokens fed into encoder model
- **Processing**: Encoder converts tokens to numerical representations

**Step 3: Vector Output**
- **Individual Vectors**: 4 vectors (one for each token)
- **Sentence Vector**: 1 additional vector for entire sentence
- **Total Output**: 5 vector representations

##### Vector Representations
**Alternative Names**: Also called vector representations or vector data
**Structure**: Numerical arrays that capture semantic meaning
**Purpose**: Designed for consumption by other models for various tasks

#### Applications of Embeddings

##### Classification Tasks
**Usage**: Vector representations used for text classification
**Process**: Models analyze embeddings to categorize text

##### Vector Databases and Semantic Search

**Semantic Search Definition**: Retrieving similar documents from corpus based on semantic meaning (not just keyword matching)

**Implementation Process**:
1. **Document Encoding**: Encode each document in corpus and store in vector database
2. **Query Encoding**: Encode user input query using same method
3. **Similarity Comparison**: Check similarity between encoded query and all documents
4. **Result Retrieval**: Return most similar/relevant documents

1. **Document Retrieval**: Use semantic search to find relevant content

**Critical Success Factor**: Good retrieval quality essential for RAG effectiveness
**Embedding Role**: Embeddings play critical role in retrieval quality

#### Decoder Models

##### Core Functionality
**Input**: Sequence of words/tokens

##### Example Process
**Input Sequence**: "They sent me a"

##### Generation Process

2. **Probability Calculation**: Compute probabilities for vocabulary
3. **Token Selection**: Choose highest probability token
4. **Output Generation**: Emit single selected token
5. **Iteration**: Repeat process for continued generation

#### Encoder-Decoder Architecture

##### Architecture Design
**Structure**: Decoder connected to encoder ("glued together")
**Primary Use**: Sequence-to-sequence tasks (especially translation)

##### Translation Example Process

**Step 1: Input Processing**
- **Input**: English words

- **Encoder Input**: Tokenized English text

**Step 2: Encoding**

**Step 3: Decoding**

**Step 4: Self-Referential Process**

- **Combined Input**: New token + rest of input sequence

##### Visual Representation
**Self-Referential Loops**: Decoder sends generated tokens back to itself
**Iterative Process**: Continues until entire target sequence generated
**Sequential Generation**: Maintains one-token-at-a-time generation pattern

**Challenge**: Not naturally designed to safely perform specific language tasks users want

#### Challenges with Completion LLMs

**Problem**: Cannot directly give instructions or ask questions to completion LLMs

**Difficulty**: This approach is challenging and not always possible

**Training Goal**: Predict next word based on internet text patterns
**User Goal**: Perform specific language tasks safely and accurately
**Gap**: Misalignment between training objective and user needs

##### Definition and Purpose
**Instruction Tuning**: Critical step in LLM alignment to make LLMs give desired responses
**Goal**: Align model behavior with user intentions and instructions
**Process**: Advanced technique involving fine-tuning pre-trained LLMs

##### Training Process
**Method**: Fine-tune pre-trained LLM on varied set of instructions

**Outcome**: Model learns to follow instructions rather than just complete text

- **Purpose**: Created specifically for chat and instruction-following

#### Reinforcement Learning from Human Feedback (RLHF)

##### Definition
**RLHF**: Model training procedure applied to fine-tuned language model to further align behavior with human preferences and instruction following

**Step 1: Human Annotation**

- Annotators compare different model outputs
- Collect human preference data

**Step 2: Reward Model Training**
- Human feedback used to train reward model
- Reward model learns patterns in human annotator preferences
- Model can automate preference decisions

**Step 3: Model Alignment**
- Use reward model to further fine-tune LLM
- Align model behavior with human preferences
- Improve instruction-following capabilities

#### Strategy 1: In-Context Learning and Few-Shot Prompting

##### In-Context Learning Definition
**Concept**: Conditioning LLM with instructions or demonstrations of intended task
**Important Note**: Not traditional learning (no model parameters change)
**Method**: Provide demonstrations of tasks model should complete

##### K-Shot Prompting
**Definition**: Explicitly providing k examples of intended task in the prompt

**Types**:
- **0-shot prompting**: Zero examples provided
- **1-shot prompting**: One example provided  
- **2-shot prompting**: Two examples provided
- **k-shot prompting**: k examples provided

##### Practical Example: Translation Task

**Task**: Translate English to French
**Format**: 3-shot prompting example

**Structure**:
1. **Task Description**: "Translate this text from English to French"
2. **Three Examples**: Previous English-French translation pairs
3. **New Prompt**: "cheese" (word to be translated)
4. **Expected Output**: French translation based on provided examples

##### Research Findings
**Established Result**: Few-shot prompting widely believed to improve results over 0-shot prompting
**Evidence Base**: Well-established through research in the field
**Practical Impact**: Providing examples generally leads to better performance

#### Strategy 2: Chain-of-Thought Prompting

##### Definition and Purpose
**Concept**: For complicated tasks, prompt model to break problem into small chunks
**Approach**: Solve step-by-step, exactly like human problem-solving
**Method**: Include reasoning steps describing calculation logic before final answer

##### Core Components
**Reasoning Step**: Describe the logic and calculations
**Intermediate Steps**: Break complex problems into smaller parts
**Final Answer**: Provide conclusion after showing work

##### Example 1: Tennis Ball Problem

**Prompt**: "Roger starts with 5 tennis balls. He buys 2 more cans of tennis balls. Each can has 3 tennis balls. How many total tennis balls does he have?"

**Chain-of-Thought Response**:
- **Reasoning**: "Starts with 5, 2 cans of 3 is 6"
- **Calculation**: "5 + 6 = 11"
- **Answer**: "The answer is 11"

##### Example 2: Oracle Cafeteria Problem

**Prompt**: "Oracle cafeteria in building 250 had 20 bananas. They use 10 to make pancakes, and they purchased 8 more. How many bananas do they have now?"

**Chain-of-Thought Response**:
- **Step 1**: "Started with 20 - 10 bananas = 10"
- **Step 2**: "They bought 8 more: 10 + 8 = 18"
- **Answer**: "Therefore, the final answer is 18 bananas"

##### Benefits of Chain-of-Thought
**Accuracy**: Reduces incorrect responses compared to direct answering
**Transparency**: Shows reasoning process for verification
**Reliability**: More consistent results on complex problems
**Debugging**: Easier to identify where errors occur in reasoning

#### Hallucination Challenge

##### Definition
**Hallucination**: Model-generated text that is non-factual and ungrounded
**Alternative Definition**: Text not grounded in any data the model has been exposed to
**Broader Scope**: Sometimes includes nonsensical or factually incorrect statements

##### Example of Hallucination
**Factually Incorrect Statement**: "In the United States, people gradually adopted the practice to drive on the left side of the road"
**Reality**: Americans drive on the right side of the road
**Problem**: Statement is completely false but presented confidently

##### Characteristics of Hallucinations

**Fluent Text**: Generated text appears completely natural and well-written
**Partial Accuracy**: Often starts with correct information before becoming false
**Subtle Nature**: Not always obvious; can be difficult to identify
**Serious Issue**: Subtle hallucinations are particularly problematic

##### Detection Challenges
**Common Misconception**: Many believe hallucinations are obvious and easy to identify
**Reality**: Hallucinations can be very subtle and difficult to detect
**Risk**: Users may accept false information due to confident presentation

#### Reducing Hallucination

##### Current Methods
**Retrieval-Augmented Systems**: RAG systems hallucinate less than 0-shot LLMs
**Grounding**: Providing factual context reduces hallucination rates
**Verification**: Cross-referencing with reliable sources

##### Research Status
**No Perfect Solution**: No known methodology to reliably prevent LLM hallucination
**Active Research**: Researchers developing methods for measuring groundedness
**Ongoing Development**: Methods for evaluating LLM-generated output reliability

##### Measurement Approaches
**Groundedness Assessment**: Techniques to verify if output is based on training data
**Factual Verification**: Methods to check accuracy of generated statements
**Reliability Metrics**: Developing standards for evaluating output trustworthiness

## Key Terms to Remember

- **AI Stack vs Oracle AI Stack distinction**: The key distinction between a generic AI stack and the Oracle AI stack is the level of integration and centralization. While a standard AI stack is a collection of components that developers assemble, Oracle offers a vertically integrated, "engineered stack" where AI is deeply embedded into its enterprise applications and databases. 
- **Four layers of Oracle AI Stack**: (SaaS → AI Services → Data → Infrastructure)
- **AGI (Artificial General Intelligence)**: Replicating human intelligence capabilities
- **AI (Artificial Intelligence)**: AGI applied to specific, narrow objectives
- **ML, DL, DS**: Machine Learning, Deep Learning, Data Science
- **Eight AI Domains**: Language, Vision, Speech, Recommendations, Anomaly Detection, Reward Learning, Forecasting, Content Generation
- **Tokenization**: Converting words to numbers for model training
- **Padding**: Making sentence lengths equal
- **Embeddings**: Representation showing word similarity
- **Sample Rate**: 44.1 kHz standard (44,100 samples/second)
- **Bit Depth**: Information richness of each audio sample
- **CNN**: Convolutional Neural Networks for vision tasks
- **RNN/LSTM**: Sequential processing architectures
- **Transformers**: Parallel processing with self-attention
- **YOLO**: You Only Look Once object detection
- **GAN**: Generative Adversarial Networks
- **Oracle Vision AI**: Four capabilities - image classification, object detection, text detection, document AI
- **Bounding Boxes**: Rectangular boundaries around detected objects
- **Confidence Scores**: Percentage certainty for AI predictions
- **Key-Value Pairs**: Structured data relationships in documents
- **Entity Extraction**: Identifying and categorizing named entities in text
- **Aspect-Based Sentiment**: Sentiment analysis for specific subjects within text
- **PII Detection**: Personal Identifiable Information recognition
- **Document Understanding**: Separate Oracle service for document analysis (evolved from Document AI)
- **Algorithm**: Specific set of rules, mathematical equations, or procedures for ML models
- **Supervised Learning**: Learning from labeled data to make predictions
- **Unsupervised Learning**: Discovering patterns in unlabeled data through clustering
- **Reinforcement Learning**: Learning through trial and error with rewards/punishments
- **Clustering**: Grouping similar data points together
